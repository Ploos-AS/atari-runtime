# Roadmap

## M0 — Foundation

- repository baseline
- MIT software licence
- Hatari-based container skeleton
- external ROM/config/artifact mounts
- dev/runtime separation
- documented Ploos-AS standards

## M1 — Hatari qualification baseline

- pin and report Hatari version
- provide reproducible ST/STE machine profiles
- add ROM discovery without redistributing TOS
- add launch and smoke-test helpers
- exercise a known test artifact produced by atari-dev

## M2 — Runtime evidence and CI

- machine-readable qualification result
- logs and screenshots as artifacts where useful
- reusable consumer workflow

## M3 — Cross-emulator and extended machines

- evaluate a second independent Atari emulator for cross-verification
- evaluate TT/Falcon profiles
- keep emulator-specific differences explicit in qualification reports
